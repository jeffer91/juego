# Pruebas manuales

1. La base azul y la roja deben comenzar produciendo soldados.
2. Una orden desde una base de soldados debe crear grupos de cinco.
3. Los grupos deben recorrer únicamente rutas válidas.
4. Dos grupos rivales cercanos deben combatir automáticamente.
5. Una base neutral debe cambiar de propietario cuando sus defensores lleguen a cero y sobrevivan atacantes.
6. Una base de drones conquistada debe comenzar a producir drones.
7. Un dron debe desaparecer después de causar daño en área.
8. La IA roja debe enviar unidades de forma periódica.
9. La captura de la base roja debe mostrar victoria.
10. La captura de la base azul debe mostrar derrota.
11. La victoria del nivel 1 debe desbloquear el nivel 2.
