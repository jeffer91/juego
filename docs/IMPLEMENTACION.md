# Implementación de los bloques 5 al 12

Esta entrega completa el prototipo funcional con soldados agrupados, movimiento táctil, combate, captura de bases, drones, inteligencia enemiga, victoria, derrota y progresión.

## Verificación recomendada en Godot

1. Abrir el proyecto con Godot 4.
2. Ejecutar `scenes/main/MainGame.tscn`.
3. Comprobar el nivel 1 desde el inicio hasta victoria o derrota.
4. Confirmar que la victoria desbloquea el nivel 2.
5. Exportar a Android después de definir el preset de exportación.
